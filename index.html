GenesisVA
Lead Operations

Ryan Roncal’s private tool for organizing business leads and tracking replies to manually linked email conversations.

Owner access onlyGmail metadata onlySending disabled

What the tool does

The integration connects a self-hosted n8n workflow to the owner’s Gmail account. It checks selected conversation metadata and updates outreach statuses in a private Base44 application and Google Sheet.

It helps the owner see whether a manually linked email has a reply and whether a follow-up needs review. Drafts remain inside the private lead queue; this Gmail connection cannot create drafts or send messages.

This information site is separate from the private GenesisVA website. It contains no lead records or access to the application.

01 / ACCESS

Headers and labels

The Google permission is gmail.metadata. The workflow uses the mailbox profile, message identifiers, headers, labels, and timestamps.

02 / LIMITS

No bodies or attachments

The connection cannot read message bodies or attachments, modify mail, create Gmail drafts, or send email.

03 / CONTROL

Disconnect anytime

The owner can revoke access in Google Account settings. The privacy policy explains stored data and deletion.
